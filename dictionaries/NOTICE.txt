Switchcraft's built-in dictionaries (switchcraft_rules.json, built into Switchcraft.exe since 1.2.0)

The rules file — word lists, letter-pair weights, word starts/ends, patterns — was generated by
Switchcraft's build tooling from word counts of these open sources:

  * Tatoeba sentences (English, Ukrainian, Russian) — https://tatoeba.org
    Licence: CC BY 2.0 FR (https://creativecommons.org/licenses/by/2.0/fr/)
  * Mozilla Common Voice, Ukrainian sentence collection (server/data/uk) —
    https://github.com/common-voice/common-voice
    Licence: CC0 1.0 (public domain dedication)
  * FrequencyWords by Hermit Dave, Ukrainian word counts (content/2018/uk/uk_full.txt), built from
    OpenSubtitles 2018 (http://opus.nlpl.eu/OpenSubtitles2018.php) — https://github.com/hermitdave/FrequencyWords
    Licence: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/)

Changes made: words were counted, filtered (alphabet, minimum counts, Russian words in the Ukrainian
lists), ranked and turned into scoring data; key maps come from the Windows keyboard layouts.

Because it adapts CC BY-SA 4.0 material, the rules file is licensed under CC BY-SA 4.0. The Switchcraft
program itself is not covered by this licence.
